# Portfolio — ปภสิฏฐ์ สุภาผล

เว็บแฟ้มสะสมผลงาน (Portfolio) หลายหน้า สองภาษา (ไทย / อังกฤษ) สำหรับสมัครเข้าศึกษาต่อ
**สาขาวิชาการแปลและล่ามในยุคดิจิทัล คณะศิลปศาสตร์ มหาวิทยาลัยธรรมศาสตร์**

## หน้าเว็บ

| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | หน้าแรก — แนะนำตัว เกรดเฉลี่ย และลิงก์ไปหน้าอื่น |
| `about.html` | เกี่ยวกับฉัน — ประวัติ ความสนใจ ทักษะ |
| `education.html` | ประวัติการศึกษา — ไทม์ไลน์และผลการเรียน |
| `achievements.html` | ผลงานและเกียรติบัตร (คลิกรูปเพื่อขยาย) |
| `goal.html` | เป้าหมาย — เหตุผลที่เลือกสาขา จดหมายแสดงเจตจำนง แผนพัฒนาตนเอง |

## โครงสร้าง

```
assets/
  css/style.css     สไตล์ทั้งหมด (สีธีมแดง-ทองแบบธรรมศาสตร์ รองรับมือถือและโหมดมืด)
  js/main.js        ปุ่มสลับภาษา, เมนูมือถือ, ขยายรูปเกียรติบัตร
  img/              รูปโปรไฟล์ ตราโรงเรียน/มหาวิทยาลัย และภาพเกียรติบัตร
  docs/             ไฟล์ PDF เกียรติบัตรฉบับจริง
```

เป็น HTML/CSS/JS ล้วน ไม่ต้องติดตั้งหรือ build อะไร — ดับเบิลคลิก `index.html` เพื่อเปิดดูในเครื่องได้เลย

## วิธีแก้ไขเนื้อหา

- ข้อความทุกจุดมี 2 ภาษาคู่กัน: `<span class="th">…</span><span class="en">…</span>` แก้ให้ครบทั้งสองภาษา
- เพิ่มเกียรติบัตรใหม่: ใส่รูปใน `assets/img/` แล้วคัดลอกบล็อก `<article class="cert">` ใน `achievements.html`
